# TRC Fotos · Web App (Torrelodones Rugby Club)

Esta es la versión web de **TRC Fotos**, lista para desplegar en cualquier hosting web gratuito (GitHub Pages, Netlify, Vercel, Firebase Hosting) o en el dominio del club (`fotos.torrelodonesrugby.com`).

## Características
- **Cero instalación:** Funciona al instante en iPhone (iOS), Android, tabletas y ordenadores.
- **Identidad Oficial TRC:** Logotipo oficial de la hormiga sobre disco amarillo, colores del club (#212121, #FFD100, verde campo).
- **8 Categorías Oficiales:**
  - Escuela
  - Sub 14
  - Sub 16
  - Sub 18
  - Senior Masculino
  - Senior Femenino
  - Touch
  - Veteranos
- **Subida múltiple de fotos:** Admite selección directa desde la cámara o el carrete de fotos.

## Cómo desplegar en GitHub Pages (Gratis en 1 minuto):
1. Crea un repositorio en GitHub llamado por ejemplo `trc-fotos`.
2. Sube los archivos de la carpeta `public/` (`index.html`, `trc_logo.png`, `trc_logo.svg`).
3. En GitHub, ve a **Settings** > **Pages** > Selecciona la rama `main` y guarda.
4. En 30 segundos tendrás tu URL pública: `https://tu-usuario.github.io/trc-fotos/`.

## Cómo conectar a tu propio dominio:
En las opciones de GitHub Pages o Vercel puedes añadir tu subdominio personalizado como `fotos.torrelodonesrugby.com`.
